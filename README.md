# Trilha-IA-Caldeira 🚀

Repositório de projetos e anotações desenvolvidos durante o programa **Geração Caldeira 2026** na trilha de **IA e Dados**, em parceria com a Alura.

## Sobre o programa
O Geração Caldeira é um programa do Instituto Caldeira para preparar jovens para o mercado de tecnologia. Esta trilha cobre Python, automação, inteligência artificial e análise de dados.

## O que você vai encontrar aqui
- Exercícios e projetos práticos de Python
- Automações com n8n e IA
- Análise de dados com Pandas e NumPy
- Projetos com APIs de IA (OpenAI, Gemini)

## Tecnologias
Python • n8n • Git/GitHub • SQL
